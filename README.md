# ระบบขอซื้อเครื่องมือช่าง — Meiwa Tool Request

Google Sheets + Apps Script • ใช้บนมือถือ • ช่างไม่ต้องมีอีเมลและไม่ต้องล็อกอิน

ช่างขอเครื่องมือด้วย **รหัสพนักงาน** → จัดซื้อร่างสเปคอ้างอิง **1 ชิ้น** ให้ช่างตรวจก่อน →
ช่างกดยืนยันว่า "สเปคถูกต้อง" (เห็นแค่สเปค **ไม่เห็นราคา**) → จัดซื้อไปเทียบราคา **อย่างน้อย 3 เจ้า**
แล้วชี้ว่าเจ้าไหนน่าซื้อที่สุด → **ฝ่ายบริหารเปิดบนจอแล้วกดอนุมัติ** (ไม่ต้องปริ้นท์) →
จัดซื้อเปิด PO ต่อ

> **กฎเหล็ก 2 ข้อ**
> 1. ช่างยืนยัน **สเปค** เท่านั้น — ราคาและการเลือกผู้ขายเป็นเรื่องของจัดซื้อกับผู้บริหาร
> 2. **จัดซื้อเปิด PO เองไม่ได้** จนกว่าผู้บริหารจะกดอนุมัติ ระบบล็อกไว้ในโค้ด

## 1. ภาพรวมการทำงาน

| ขั้น | ใคร | เกิดอะไรขึ้น | สถานะที่เห็น |
|---|---|---|---|
| 1 | **ช่าง** | ขอเครื่องมือหลายรายการในใบเดียว + รหัสพนักงาน + รูป + ราคาที่เห็นที่ร้าน (ถ้ามี) | รอจัดซื้อร่างสเปค |
| 2 | **จัดซื้อ** | ร่างสเปคอ้างอิง 1 ชิ้น (ยี่ห้อ/รุ่น/รูป) ส่งให้ช่างตรวจ | รอช่างตรวจสเปค |
| 3 | **ช่าง** | ✅ สเปคถูกต้อง / 🔄 ขอแก้ไข / ❌ ใช้ไม่ได้ — **ทีละรายการ ไม่เห็นราคา** | เทียบราคา |
| 4 | **จัดซื้อ** | เทียบราคา **≥ 3 เจ้า** แล้วกด ★ แนะนำเจ้าที่น่าซื้อที่สุด + เหตุผล | รอผู้บริหาร |
| 5 | **ผู้บริหาร** | เปิดบนจอ เห็นตารางเทียบครบ กด ✅ อนุมัติ (รายรายการ หรือทั้งใบ) | อนุมัติแล้ว |
| 6 | **จัดซื้อ** | เปิด PO → รับของ → ปิดงาน | เสร็จสิ้น |

**ถ้าผู้บริหารเลือกราคาที่ช่างไปดูมาเองที่ร้าน** ระบบจะสลับเป็นโหมด "ช่างซื้อเอง" อัตโนมัติ —
ส่งข้อมูลใบกำกับภาษีบริษัทให้ช่างทาง LINE แล้วให้ช่างอัปโหลดใบเสร็จกลับ

**4 หน้าจอ**

| หน้า | ลิงก์ | ใคร | เข้าอย่างไร |
|---|---|---|---|
| ฟอร์มขอซื้อ | `<WEBAPP_URL>` | ช่าง | ไม่ต้องล็อกอิน |
| ติดตาม/ยืนยันสเปค | `<WEBAPP_URL>?p=r&t=<token>` | ช่าง | ลิงก์ที่ส่งทาง LINE |
| แดชบอร์ดจัดซื้อ | `<WEBAPP_URL>?p=dash` | จัดซื้อ | `STAFF_PIN` |
| **อนุมัติสั่งซื้อ** | `<WEBAPP_URL>?p=mgr` | ผู้บริหาร | `MGR_PIN` (คนละตัว) |
| ค้นหาคำขอของฉัน | `<WEBAPP_URL>?p=find` | ช่าง | รหัสพนักงานหรือชื่อ |

## 2. โครงสร้างข้อมูล (Google Sheet structure)

ระบบสร้าง 7 ชีตให้อัตโนมัติตอนติดตั้ง **หัวตารางแถวที่ 1 ห้ามแก้ชื่อหรือสลับลำดับ**
(โค้ดอ่าน/เขียนตามชื่อคอลัมน์)

| ชีต | เก็บอะไร |
|---|---|
| `Requests` | 1 แถว = 1 ใบขอซื้อ (มีรหัสพนักงานผู้ขอ) |
| `Items` | 1 แถว = **1 เครื่องมือ** — หัวใจของระบบ |
| `Options` | 1 แถว = ราคา 1 เจ้า (1 เครื่องมือมีได้หลายเจ้า) |
| `History` | ทุกการกด ต่อท้ายอย่างเดียว **ห้ามลบ** |
| `Technicians` | รหัสพนักงาน + ชื่อช่าง |
| `Config` | PIN ทั้งสองตัว, อีเมล, VAT, จำนวนเจ้าขั้นต่ำ, ข้อมูลใบกำกับภาษี |
| `Notifications` | คิวข้อความ LINE/อีเมล พร้อมสถานะส่งแล้ว/ยังไม่ส่ง |

**เลขที่เอกสาร** — `REQ-2026-0001` (เริ่มใหม่ทุกปี) → รายการย่อย `REQ-2026-0001-01` →
ราคาแต่ละเจ้า `REQ-2026-0001-01-O1`

### คอลัมน์สำคัญ

**`Technicians` (6)** — `emp_code` `name` `nickname` `site` `line_id` `active`
ใส่รหัสพนักงานให้ครบก่อนใช้งานจริง ช่างเลือกชื่อแล้วระบบเติมรหัสให้เอง

**`Requests` (11)** — `req_id` `token` `created_at` **`emp_code`** `requester_name` `site`
`contact` `required_date` `note` `status` `updated_at`

**`Items` (45)** แบ่งเป็น 6 กลุ่มตามลำดับงาน

| กลุ่ม | คอลัมน์ | ใครเขียน |
|---|---|---|
| สิ่งที่ช่างขอ | `item_id` `req_id` `seq` `tool_name` `qty` `unit` `required_date` `intended_use` `spec_pref` `brand_pref` `item_note` `ref_links` `ref_photos` | ช่าง |
| ราคาที่ช่างไปดูมาเอง | `bench_price` `bench_store` `bench_note` `bench_photo` `bench_by` `bench_at` | ช่าง (ตอนขอ หรือทีหลัง) |
| สเปคอ้างอิง 1 ชิ้น | `spec_brand` `spec_model` `spec_detail` `spec_photo` `spec_link` `spec_by` `spec_at` | จัดซื้อ |
| ช่างยืนยันสเปค | `tech_status` `tech_note` `tech_by` `tech_at` | ช่าง |
| จัดซื้อเทียบราคา | `pur_note` `recommend_option_id` `recommend_reason` `quoted_at` `purchase_status` | จัดซื้อ |
| ผู้บริหารอนุมัติ | `approved_option_id` `buy_mode` `mgr_by` `mgr_at` `mgr_note` | **ผู้บริหารเท่านั้น** |
| PO / ใบเสร็จ | `po_ref` `po_by` `po_at` `tax_invoice_ok` `actual_price` `receipt_url` `receipt_at` | จัดซื้อ / ช่าง |

**`Options` (22)** — `option_id` `item_id` `created_at` `created_by` **`source`** `brand` `model`
`spec` `supplier` `product_link` `photo_url` `unit_price` `vat_rate` `vat_amount` `shipping`
`subtotal` `total_cost` `availability` `delivery_date` `payment_terms` `note` `status`

`source` = `SUPPLIER` (จัดซื้อไปขอราคามา) หรือ `TECH` (ราคาที่ช่างไปดูมาเองที่ร้าน)
ช่อง `subtotal` `vat_amount` `total_cost` ระบบคำนวณให้ (`vat = (subtotal + shipping) × vat_rate%`)

**`History` (8)** — `ts` `req_id` `item_id` `option_id` `actor` `role` `action` `detail`
`role` มี 3 ค่า: `TECH` / `PURCHASING` / `MANAGEMENT`

### สถานะ

| คอลัมน์ | ค่า | ใครเปลี่ยน |
|---|---|---|
| `tech_status` | `NO_SPEC` → `WAITING` → `CONFIRMED` / `CHANGE` / `REJECTED` | ช่าง |
| `purchase_status` | `NEW` → `WAITING_TECH` → `QUOTING` → `PENDING_APPROVAL` → `APPROVED` → `PO_ISSUED` → `RECEIVED` → `CLOSED` (หรือ `REJECTED` / `CANCELLED`) | จัดซื้อ + **ผู้บริหาร** |

ระบบรวมสองคอลัมน์เป็น **ขั้นตอนเดียวที่แสดงบนจอ (stage)** = แท็บบนแดชบอร์ด

| stage | แท็บ | ใครต้องลงมือ |
|---|---|---|
| `NEED_SPEC` | ร่างสเปค | จัดซื้อ |
| `TECH_SPEC` | รอช่างตรวจสเปค | ช่าง |
| `SPEC_CHANGE` | ช่างขอแก้สเปค | จัดซื้อ |
| `QUOTING` | เทียบราคา | จัดซื้อ (ต้องครบ 3 เจ้า + เลือกตัวแนะนำ) |
| `APPROVAL` | รอผู้บริหาร | **ผู้บริหาร** |
| `TO_PO` | รอเปิด PO | จัดซื้อ |
| `ORDERED` | เปิด PO แล้ว | รอของ |
| `LOCAL_BUY` | ช่างซื้อเอง | ช่าง (อัปโหลดใบเสร็จ) |
| `DONE` / `MGR_REJECTED` / `CANCELLED` | — | — |

### กฎที่บังคับในโค้ด (ไม่ใช่แค่ข้อตกลง)

- เพิ่มราคาไม่ได้ ถ้าช่างยังไม่ยืนยันสเปค → `apiAddOption` throw
- ส่งอนุมัติไม่ได้ ถ้าเทียบไม่ครบ `MIN_QUOTES` เจ้า หรือยังไม่เลือกตัวที่แนะนำ → `apiSubmitForApproval` throw
- **เปิด PO ไม่ได้ ถ้าผู้บริหารยังไม่อนุมัติ** → `apiIssuePO` throw
- อนุมัติได้เฉพาะ `mgrToken` เท่านั้น — ไม่มี API ให้จัดซื้อกดอนุมัติเลย
- หน้าช่างไม่ได้รับข้อมูลราคาผู้ขายแม้แต่ช่องเดียว รวมถึงในประวัติ (`techHistory_` กรองให้)

## 3. ติดตั้ง (ประมาณ 10 นาที)

### 3.1 สร้าง Google Sheet และโปรเจกต์ Apps Script

1. ไปที่ [sheets.new](https://sheets.new) ตั้งชื่อ **Meiwa Tool Request**
2. **ส่วนขยาย (Extensions) → Apps Script**
3. ตั้งชื่อโปรเจกต์ `Meiwa Tool Request`
4. **⚙️ Project Settings** → ติ๊ก **Show "appsscript.json" manifest file in editor**
   และตั้ง Time zone เป็น **(GMT+07:00) Bangkok**

### 3.2 คัดลอกไฟล์จากโฟลเดอร์ `apps-script/`

| ในตัวแก้ไข Apps Script | ชนิด |
|---|---|
| `Code` `Config` `Db` `Workflow` `Files` `Notify` `Setup` `Api` | Script (.gs) |
| `Style` `ClientLib` `Page_New` `Page_Tech` `Page_Dash` **`Page_Mgr`** `Page_Find` `Page_Error` | **HTML** |
| `appsscript.json` | Manifest |

> ⚠️ **ชื่อไฟล์ต้องตรงตัวพิมพ์ใหญ่-เล็กเป๊ะ** เพราะโค้ดเรียกไฟล์ HTML ตามชื่อนี้

กด **💾 Save** แล้วกลับไปที่ Google Sheet **ปิดแล้วเปิดใหม่** จะเห็นเมนู **🔧 Meiwa Tool Request**

### 3.3 รันการติดตั้ง

เมนู **🔧 → 1) ติดตั้งระบบ** แล้วกด Review permissions → Allow

### 3.4 แก้ค่าตั้งต้นในชีต `Config` (สำคัญ)

| key | ต้องแก้ | หมายเหตุ |
|---|---|---|
| `STAFF_PIN` | ✅ | รหัสฝ่ายจัดซื้อ |
| `MGR_PIN` | ✅ | **รหัสผู้บริหาร — ต้องไม่ซ้ำกับ STAFF_PIN** |
| `MIN_QUOTES` | | จำนวนเจ้าขั้นต่ำ ค่าเริ่มต้น `3` |
| `PURCHASING_EMAILS` | ✅ | อีเมลทีมจัดซื้อ คั่นด้วย `,` |
| `MANAGEMENT_EMAILS` | ✅ | อีเมลผู้บริหารที่รับแจ้งเตือนรายการรออนุมัติ |
| `COMPANY_NAME` `COMPANY_TAX_ID` `COMPANY_BRANCH` `COMPANY_ADDRESS` | ✅ | ข้อมูลใบกำกับภาษี — ตอนนี้เป็น placeholder |
| `APPROVAL_LIMIT` | | ยอดเกินนี้ หน้าผู้บริหารจะขึ้นแถบเตือนสีส้ม |

จากนั้นใส่ **รหัสพนักงานและรายชื่อช่าง** ในชีต `Technicians`

## 4. Deploy เว็บแอป

**Deploy → New deployment → ⚙️ → Web app**

| ช่อง | ค่า |
|---|---|
| Execute as | **Me** |
| Who has access | **Anyone** |

> ต้องเป็น *Anyone* เพราะช่างไม่มีบัญชี Google บริษัท ความปลอดภัยมาจาก token ในลิงก์ + PIN 2 ชั้น

คัดลอก Web app URL แล้ววางในชีต `Config → WEBAPP_URL`
**ทุกครั้งที่แก้โค้ด ต้อง Deploy → Manage deployments → ✏️ → Version: New version → Deploy**

## 5. ทดสอบ (ประมาณ 15 นาที)

เตรียม: มือถือ 1 เครื่อง (ช่าง) + คอม 1 เครื่อง (จัดซื้อ) + หน้าต่าง Incognito (ผู้บริหาร)

| # | ทำอะไร | ต้องเห็นอะไร |
|---|---|---|
| 1 | **[ช่าง]** เปิด `<WEBAPP_URL>` เลือกชื่อตัวเอง | **รหัสพนักงานถูกเติมให้อัตโนมัติ** |
| 2 | กรอก 3 รายการ รายการแรกใส่สเปค + ยี่ห้อที่อยากได้ + **ราคาที่เห็นที่ Global House** + ถ่ายรูปของเดิม → ส่ง | ขึ้นเลข `REQ-2026-0001` + ลิงก์ติดตาม |
| 3 | ดูชีต `Items` | คอลัมน์ `emp_code` `bench_price` `bench_store` มีค่า |
| 4 | **[จัดซื้อ]** `?p=dash` ใส่ `STAFF_PIN` | แท็บ "ร่างสเปค 3" |
| 5 | ลองกด "เพิ่มราคาอีกเจ้า" ทันที | **ไม่มีปุ่มให้กด** — ต้องให้ช่างยืนยันสเปคก่อน ← ตรวจข้อนี้ |
| 6 | กด **📤 ส่งสเปคให้ช่างตรวจ** ใส่ยี่ห้อ/รุ่น/รายละเอียด + รูป → ส่ง | ย้ายไปแท็บ "รอช่างตรวจสเปค" |
| 7 | **[ช่าง]** เปิดลิงก์ในมือถือ | เห็นรูปและสเปค **ไม่เห็นราคาหรือชื่อผู้ขายเลย** ← ตรวจข้อนี้ |
| 8 | รายการ 1 กด **✅ สเปคถูกต้อง** | ย้ายไปแท็บ "เทียบราคา" ฝั่งจัดซื้อ |
| 9 | รายการ 2 กด **🔄 ขอแก้ไข** ใส่เหตุผล | ไม่ใส่เหตุผลจะกดส่งไม่ได้ ← ตรวจข้อนี้ |
| 10 | รายการ 3 กด **🏪 ใส่ราคาที่เห็นที่ร้าน** (ที่ลืมใส่ตอนขอ) | จัดซื้อได้อีเมลแจ้งทันที |
| 11 | **[จัดซื้อ]** รายการ 1 เพิ่มราคา 2 เจ้า แล้วกด **➕ ใช้ราคานี้เป็น 1 เจ้า** (ราคาช่าง) | นับเป็น **3/3 เจ้า** |
| 12 | ลองกด **📨 ส่งให้ผู้บริหาร** ก่อนกด ★ แนะนำ | ขึ้นเตือนว่ายังไม่ได้เลือกตัวที่แนะนำ ← ตรวจข้อนี้ |
| 13 | กด **★ แนะนำเจ้านี้** ใส่เหตุผล → **📨 ส่งให้ผู้บริหาร** | ย้ายไปแท็บ "รอผู้บริหาร" + ผู้บริหารได้อีเมลพร้อมตารางเทียบ |
| 14 | **[ผู้บริหาร]** เปิด `?p=mgr` ใส่ `MGR_PIN` | เห็นทั้งใบในหน้าจอเดียว ตารางเทียบ 3 เจ้า ป้าย "ถูกที่สุด" / "แพงกว่าถูกสุด ฿xxx" |
| 15 | แตะเลือกเจ้าอื่นที่ไม่ใช่ที่จัดซื้อแนะนำ | แถบล่างเปลี่ยนตาม บอกว่าจะเปิด PO หรือให้ช่างซื้อเอง |
| 16 | เลือก **ราคาที่ช่างไปดูมา** แล้วกด ✅ อนุมัติ | สถานะเป็น "ช่างซื้อเอง" อัตโนมัติ |
| 17 | **[จัดซื้อ]** ลองเปิด PO รายการนั้น | **เปิดไม่ได้** — ผู้บริหารให้ช่างซื้อเอง ← ตรวจข้อนี้ |
| 18 | รายการที่อนุมัติแบบผู้ขาย ใส่เลข PO → บันทึก | ย้ายไปแท็บ "เปิด PO แล้ว" |
| 19 | กด **📱 ข้อความ LINE** | ข้อความซื้อเองมี **ชื่อบริษัท เลขผู้เสียภาษี สาขา ที่อยู่** ครบ |
| 20 | **[ช่าง]** รายการซื้อเอง → ใส่ราคาจริง + รูปใบเสร็จ → ส่ง | สถานะ "เสร็จสิ้น" |
| 21 | **[ผู้บริหาร]** ใบที่มีหลายรายการรออนุมัติ | มีปุ่ม **✅ อนุมัติทั้งใบ N รายการ — ฿xxx** |

## 6. ใช้งานประจำวัน

**ช่าง** — ไม่ต้องจำรหัส ไม่ต้องมีอีเมล
1. เปิดลิงก์ฟอร์ม (ปักหมุดใน LINE กลุ่ม หรือทำ QR ติดบอร์ด) เลือกชื่อ → รหัสมาเอง
2. ส่งคำขอ → คัดลอกลิงก์ติดตามเก็บไว้ในแชทตัวเอง
3. จัดซื้อส่งสเปคมา → กด ✅ / 🔄 / ❌ **ดูแค่ว่าของใช้กับงานได้ไหม**
4. ไปเจอราคาถูกที่ร้าน → เปิดลิงก์เดิม กด 🏪 ใส่ราคาเข้าไปได้ตลอด
5. ลิงก์หาย → `?p=find` พิมพ์รหัสพนักงาน

**จัดซื้อ** — เปิด `?p=dash` วันละครั้ง ไล่แท็บซ้าย→ขวา
`ร่างสเปค → ช่างขอแก้สเปค → รอช่างตรวจสเปค → เทียบราคา → รอผู้บริหาร → รอเปิด PO`
หลังส่งสเปคหรืออนุมัติทุกครั้ง กด **📱 ข้อความ LINE → คัดลอก** แล้ววางในแชทช่าง

**ผู้บริหาร** — เปิด `?p=mgr` เห็นเฉพาะคิว "รออนุมัติ"
ทุกใบแสดงตารางเทียบครบในจอเดียว ไม่ต้องปริ้นท์ ไม่ต้องเปิดไฟล์แนบ
กดอนุมัติรายรายการ (เลือกเจ้าเองได้) หรือกดทีเดียวทั้งใบตามที่จัดซื้อแนะนำ

## 7. ข้อควรรู้และข้อจำกัด

**ความปลอดภัย** — ออกแบบให้ใช้ภายในองค์กร แลกกับความสะดวกของช่างที่ไม่มีอีเมล
- ลิงก์ของช่างใช้ token สุ่ม 16 ตัวอักษร **ใครมีลิงก์ก็เปิดได้** จึงบังคับให้เลือกชื่อผู้กดทุกครั้ง
  และบันทึกชื่อ+เวลาไว้เสมอ ไม่ควรส่งลิงก์ออกนอกบริษัท
- **PIN 2 ชั้นแยกกัน** — `STAFF_PIN` กับ `MGR_PIN` ต้องไม่ซ้ำกัน เปลี่ยนทันทีหลังติดตั้ง
  และเปลี่ยนเมื่อมีคนย้ายออก เซสชันหมดอายุใน 6 ชั่วโมง
- PIN คือการกันคนกดผิดฝ่าย ไม่ใช่ระบบยืนยันตัวตนระดับธนาคาร — ถ้าต้องการเข้มกว่านี้
  ให้เปลี่ยนหน้า `?p=mgr` ไปใช้ Google login (ต้องแก้โค้ดเพิ่ม)

**รูปภาพ** — เก็บใน Drive ของผู้ที่ deploy ตั้งเป็น "ผู้ที่มีลิงก์ดูได้" อัตโนมัติ
ถ้าองค์กรปิดการแชร์แบบลิงก์ ให้เปิดโฟลเดอร์ **Meiwa Tool Request - Files**
แล้วตั้งการแชร์เป็น *Anyone with the link → Viewer* ด้วยมือ
รูปถูกย่อเหลือด้านยาวสุด 1,400 px ในเครื่องก่อนอัปโหลด

**อีเมล** — ส่งจากบัญชีที่ deploy โควตา 100 ฉบับ/วัน (ฟรี) หรือ 1,500 ฉบับ/วัน (Workspace)

**LINE** — ค่าเริ่มต้นคือ "คัดลอกแล้ววางในแชท" ใช้ได้ทันที
ถ้าต้องการส่งอัตโนมัติ ใส่ `LINE_CHANNEL_TOKEN` + `line_id` ของช่าง

**ขนาดที่รองรับ** — หลักพันรายการต่อปี ถ้าชีต `Items` เกิน ~5,000 แถว แดชบอร์ดจะเริ่มช้า
ให้ย้ายข้อมูลปีเก่าออกไปไฟล์อื่น

**ยังไม่มีในเวอร์ชันนี้** — ออกเอกสาร PO เป็น PDF, เชื่อมระบบบัญชี, งบประมาณรายแผนก,
ผู้อนุมัติหลายระดับตามวงเงิน, รายงานสรุปรายเดือน
