# คู่มือใช้งานอย่างย่อ (พิมพ์แจกได้)

---

## 📱 สำหรับช่าง — ขอซื้อเครื่องมือ

### ส่งคำขอ
1. เปิดลิงก์ฟอร์ม (ปักหมุดไว้ในแชท LINE กลุ่ม)
2. เลือกชื่อตัวเอง + วันที่ต้องการใช้
3. กรอกทีละรายการ กด **➕ เพิ่มเครื่องมืออีกรายการ** ขอพร้อมกันได้หลายอย่าง
4. สิ่งที่ช่วยให้ได้ของตรงที่สุด — ใส่ให้ครบเท่าที่มี
   - 📷 **รูปเครื่องมือตัวเดิมที่ใช้อยู่** (ถ่ายจากมือถือได้เลย)
   - 🔗 **ลิงก์สินค้า** จากเว็บร้าน / Shopee / Lazada
   - ⚙️ **สเปคหรือยี่ห้อที่ต้องการ** เช่น "SDS-Plus 800W ขึ้นไป Bosch หรือ Makita"
   - 💰 **ราคาที่เห็นที่ร้าน** เช่น Global House + ชื่อร้าน (จัดซื้อใช้เทียบราคา)
   - 🔧 **ใช้ทำอะไร** เพื่อให้จัดซื้อเลือกรุ่นที่เหมาะกับงาน
5. กด **ส่งคำขอ** → กด **📋 คัดลอกลิงก์** แล้ว **วางในแชท LINE ของตัวเอง**

> ⚠️ ลิงก์นี้คือที่เดียวที่จะกลับมาดูราคาและกดยืนยันได้ อย่าลืมเก็บไว้
> ลิงก์หาย? เปิดหน้าเว็บ → **ค้นหาคำขอของฉัน** แล้วพิมพ์ชื่อตัวเอง

### เมื่อจัดซื้อเสนอราคามาแล้ว
เปิดลิงก์ → เลือกชื่อตัวเองในช่อง **"ฉันคือ"** (ทำครั้งเดียว ระบบจำให้)

แต่ละรายการจะมีการ์ดของตัวเอง ตัดสินใจ **แยกทีละรายการ** ได้เลย

| ปุ่ม | ใช้เมื่อ |
|---|---|
| ✅ **ตรงสเปค ยืนยัน** | ของถูกต้อง ใช้กับงานได้ |
| ❌ **ไม่ตรงสเปค** | ใช้ไม่ได้ — ต้องบอกเหตุผล เช่น "กำลังไฟน้อยไป" |
| ✏️ **ขอให้แก้ไข** | เกือบใช่ — บอกว่าอยากให้แก้อะไร |

แตะรูปเพื่อดูเต็มจอ • กด "ดูรายละเอียดราคา" เพื่อดูราคาต่อหน่วย ค่าส่ง และ VAT
แถบสีเขียว/ส้มใต้แต่ละตัวเลือกบอกว่า **ถูกกว่าหรือแพงกว่าราคาที่ร้านที่คุณเห็นมา**

### เลือกวิธีซื้อ
หลังยืนยันสเปค จะมีตารางเทียบให้เลือก

- 🚚 **ให้จัดซื้อสั่งซื้อ** — ผู้ขายออกใบกำกับภาษีให้บริษัทโดยตรง รอของตามวันที่ระบุ
- 🏪 **ซื้อเองที่ร้าน** — ได้ของเร็ว ต้อง
  1. ใส่ราคาประเมินต่อหน่วย
  2. ใส่ชื่อร้าน
  3. **ติ๊กยืนยันว่าร้านออกใบกำกับภาษี/ใบเสร็จในนามบริษัทได้** (ถ้าไม่ติ๊กจะส่งไม่ได้)

> 🛑 **อย่าเพิ่งไปซื้อจนกว่าสถานะจะเปลี่ยนเป็น "อนุมัติให้ซื้อเองที่ร้านแล้ว"**
> การยืนยันสเปคยังไม่ใช่การอนุมัติ ต้องรอฝ่ายจัดซื้ออนุมัติก่อนเสมอ

### หลังซื้อเองที่ร้าน
1. ก่อนไปซื้อ กด **📋 คัดลอกข้อมูลบริษัท** แล้วยื่นให้ร้านออกใบกำกับภาษี
2. ซื้อเสร็จ เปิดลิงก์เดิม → ใส่ราคาจริง → เลือกรูปใบเสร็จ → **📤 ส่งใบเสร็จ**

## 💼 สำหรับฝ่ายจัดซื้อ

เปิด `<WEBAPP_URL>?p=dash` ใส่ชื่อและ PIN (เซสชันอยู่ได้ 6 ชั่วโมง)

### ไล่งานตามแท็บ ซ้าย → ขวา

| แท็บ | ต้องทำอะไร |
|---|---|
| **รอเสนอราคา** | หาของ แล้วกด ➕ เพิ่มตัวเลือก (ใส่ได้หลายตัวเลือกต่อ 1 รายการ) |
| **รอช่างยืนยัน** | รอช่าง — กด 📱 ข้อความ LINE ส่งเตือนถ้ายังเงียบ |
| **รอเลือกวิธีซื้อ** | รอช่างเลือกว่าให้สั่งหรือซื้อเอง |
| **รออนุมัติ** | ตรวจยอดแล้วกด ✅ อนุมัติ หรือ ❌ ไม่อนุมัติ (ต้องใส่เหตุผล) |
| **รอสั่งซื้อ** | สั่งกับผู้ขาย แล้วกด 📦 บันทึกว่าสั่งซื้อแล้ว → ✅ รับของแล้ว |
| **ช่างซื้อเอง** | รอช่างอัปโหลดใบเสร็จ |

### เพิ่มตัวเลือกให้ครบ ช่างจะตัดสินใจได้เร็วขึ้น
รูปสินค้า • ยี่ห้อ/รุ่น • สเปคสำคัญ • ผู้ขาย • ราคา/หน่วย • VAT • ค่าส่ง •
สถานะสินค้า • วันที่ได้ของ • เงื่อนไขชำระเงิน • ลิงก์สินค้า
ระบบคำนวณยอดรวมและ VAT ให้อัตโนมัติ ติ๊ก "จัดซื้อแนะนำ" เพื่อชี้ตัวเลือกที่ดีที่สุด

### แจ้งช่าง (ช่างไม่มีอีเมล)
ทุกครั้งที่เพิ่มตัวเลือกหรืออนุมัติ → กด **📱 ข้อความ LINE → 📋 คัดลอก** → วางในแชทช่าง
ข้อความมีลิงก์ให้ช่างกดยืนยันได้ทันที
รายการที่อนุมัติให้ซื้อเอง ข้อความจะแนบ **ชื่อบริษัท เลขผู้เสียภาษี สาขา ที่อยู่** ให้ครบ
ถ้ายังไม่ได้ส่ง จะมีแถบเหลือง "มีข้อความรอส่งให้ช่างทาง LINE" ค้างไว้เตือน

ปุ่ม **💬 ส่งข้อความถึงช่าง** ใช้คุยเรื่องเฉพาะรายการ เช่น
"รุ่นนี้ที่ Global House ถูกกว่า 600 บาท และได้ของวันนี้ แนะนำให้ซื้อเองแล้วเบิกคืน"

### เรื่องที่ต้องระวัง
- **การที่ช่างยืนยันสเปค ไม่ใช่การอนุมัติสั่งซื้อ** ต้องกดอนุมัติในแท็บ "รออนุมัติ" ก่อนเสมอ
- ยอดเกินวงเงินใน `Config → APPROVAL_LIMIT` ระบบจะขึ้นแถบส้มเตือนให้ผู้จัดการเป็นผู้อนุมัติ
- ทุกการกดถูกบันทึกชื่อและเวลา ดูย้อนหลังได้ที่ปุ่ม **🕘 ประวัติ** หรือชีต `History`
