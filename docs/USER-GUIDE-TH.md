# คู่มือใช้งานอย่างย่อ (พิมพ์แจกได้)

**กฎ 2 ข้อที่ทุกฝ่ายต้องรู้**
1. ช่างยืนยันแค่ **สเปค** — ช่างไม่เห็นราคาและไม่ได้เลือกผู้ขาย
2. **ผู้บริหารเท่านั้นที่อนุมัติได้** จัดซื้อเปิด PO ก่อนอนุมัติไม่ได้ ระบบล็อกไว้

---

## 📱 สำหรับช่าง

### ส่งคำขอ
1. เปิดลิงก์ฟอร์ม (ปักหมุดไว้ในแชท LINE กลุ่ม)
2. **เลือกชื่อตัวเองจากรายการ → รหัสพนักงานขึ้นให้อัตโนมัติ** (ถ้าไม่มีชื่อ ให้พิมพ์รหัสเอง)
3. ใส่วันที่ต้องการใช้ แล้วกรอกทีละรายการ กด **➕ เพิ่มเครื่องมืออีกรายการ** ได้เรื่อย ๆ
4. ใส่ให้ครบเท่าที่มี ยิ่งครบยิ่งได้ของตรง
   - 📷 **รูปเครื่องมือตัวเดิม** (ถ่ายจากมือถือได้เลย)
   - ⚙️ **สเปคที่ต้องการ** เช่น "ช่วงวัด 0–10 มม. ละเอียด 0.01 มม."
   - 🏷️ **ยี่ห้อ/รุ่นที่อยากได้** เช่น "Mitutoyo 2046A หรือเทียบเท่า"
   - 💰 **ราคาที่เห็นที่ร้าน** เช่น Global House — ไม่มีก็เว้นว่าง ใส่ทีหลังได้
   - 🔧 **ใช้ทำอะไร** • 📝 **หมายเหตุ** • 🔗 **ลิงก์สินค้า**
5. กด **ส่งคำขอ** → **📋 คัดลอกลิงก์** แล้ววางในแชท LINE ของตัวเอง

> ⚠️ ลิงก์นี้คือที่เดียวที่จะกลับมาตรวจสเปคและติดตามสถานะได้
> ลิงก์หาย? เปิดหน้าเว็บ → **ค้นหาคำขอของฉัน** แล้วพิมพ์ **รหัสพนักงาน**

### เมื่อจัดซื้อส่งสเปคมาให้ตรวจ
เปิดลิงก์ → เลือกชื่อตัวเองในช่อง **"ฉันคือ"** (ทำครั้งเดียว ระบบจำให้)

จัดซื้อจะเลือกของมาให้ดู **1 ชิ้น** พร้อมรูปและสเปค ดูแล้วตอบว่า

| ปุ่ม | ใช้เมื่อ |
|---|---|
| ✅ **สเปคถูกต้อง** | ของแบบนี้ใช้กับงานได้ |
| 🔄 **ขอแก้ไข** | เกือบใช่ — บอกว่าอยากให้แก้อะไร (ต้องพิมพ์เหตุผล) |
| ❌ **ใช้ไม่ได้** | ใช้กับงานไม่ได้ (ต้องพิมพ์เหตุผล) |

> 💡 **หน้านี้ไม่มีราคาให้ดู และไม่ต้องเลือกร้าน** — ดูแค่ว่า "ของชิ้นนี้ทำงานได้ไหม"
> เรื่องราคาและร้าน จัดซื้อกับผู้บริหารจัดการให้

### เจอราคาถูกที่ร้าน — ส่งให้จัดซื้อได้ตลอด
กด **🏪 ใส่ราคาที่เห็นที่ร้าน** ใส่ราคา + ชื่อร้าน + ถ่ายรูปป้ายราคา
จัดซื้อจะเอาราคานี้ไปเทียบกับผู้ขาย **ถ้าผู้บริหารเห็นว่าร้านคุ้มกว่า อาจให้คุณไปซื้อเองเลย**

### ถ้าผู้บริหารอนุมัติให้ซื้อเอง
1. หน้าจะขึ้น **วงเงินที่อนุมัติ** และข้อมูลบริษัท
2. กด **📋 คัดลอกข้อมูลบริษัท** ยื่นให้ร้านออกใบกำกับภาษี
3. ซื้อเสร็จ → เปิดลิงก์เดิม → ใส่ราคาจริง → ถ่ายรูปใบเสร็จ → **📤 ส่งใบเสร็จ**

> 🛑 **อย่าไปซื้อก่อนเห็นข้อความ "ผู้บริหารอนุมัติให้ซื้อเองแล้ว"**

## 💼 สำหรับฝ่ายจัดซื้อ

เปิด `<WEBAPP_URL>?p=dash` ใส่ชื่อและ **STAFF_PIN** (เซสชัน 6 ชั่วโมง)

### ไล่งานตามแท็บ ซ้าย → ขวา

| แท็บ | ต้องทำอะไร |
|---|---|
| **ร่างสเปค** | เลือกของที่น่าจะตรง **1 ชิ้น** ใส่ยี่ห้อ/รุ่น/รูป → **📤 ส่งสเปคให้ช่างตรวจ** |
| **ช่างขอแก้สเปค** | อ่านเหตุผลในกรอบเหลือง แก้สเปคแล้วส่งใหม่ |
| **รอช่างตรวจสเปค** | รอช่าง — กด 📱 ข้อความ LINE เตือนถ้าเงียบ |
| **เทียบราคา** | ขอราคา **ให้ครบ 3 เจ้า** → กด ★ แนะนำ → 📨 ส่งให้ผู้บริหาร |
| **รอผู้บริหาร** | รออนุมัติ — ดึงกลับมาแก้ได้ถ้ายังไม่มีใครกด |
| **รอเปิด PO** | ใส่เลข PO → บันทึก |
| **เปิด PO แล้ว** | ของมาถึง → กด 📦 รับของแล้ว |
| **ช่างซื้อเอง** | กด 📱 ส่งข้อมูลใบกำกับภาษีให้ช่าง แล้วรอใบเสร็จ |

### กฎที่ระบบบังคับ (กดข้ามไม่ได้)
- **ยังเพิ่มราคาไม่ได้** จนกว่าช่างจะกด ✅ สเปคถูกต้อง
- **ยังส่งอนุมัติไม่ได้** จนกว่าจะครบ 3 เจ้า **และ** เลือกตัวที่แนะนำแล้ว
- **ยังเปิด PO ไม่ได้** จนกว่าผู้บริหารจะอนุมัติ

### เคล็ดลับ
- ถ้าช่างใส่ราคาจากร้านมาให้ กด **➕ ใช้ราคานี้เป็น 1 เจ้า** จะนับเป็น 1 ใน 3 เจ้าทันที
- ★ แนะนำควรใส่เหตุผลสั้น ๆ เช่น "ถูกกว่า 300 ได้ของเร็วกว่า 3 วัน มีใบรับรอง"
  ผู้บริหารอ่านบรรทัดนี้เป็นหลัก
- ข้อความถึงช่าง **ไม่ควรใส่ราคาผู้ขาย** เพราะช่างไม่ได้มีหน้าที่ดูราคา

## ✅ สำหรับฝ่ายบริหาร

เปิด `<WEBAPP_URL>?p=mgr` ใส่ชื่อและ **MGR_PIN** (คนละรหัสกับจัดซื้อ)

### หน้าจอเดียวจบ ไม่ต้องปริ้นท์
แต่ละใบขอซื้อแสดง:
- ผู้ขอ + **รหัสพนักงาน** + วันที่ต้องการใช้
- **ยอดรวมตามที่จัดซื้อแนะนำ** (ขึ้นแถบส้มถ้าเกินวงเงินที่ตั้งไว้)
- ทุกรายการ พร้อมป้าย **✔ ช่างยืนยันสเปคแล้ว** (ใคร เมื่อไร)
- **ตารางเทียบราคาครบทุกเจ้า** เรียงจากถูกไปแพง
  - ป้าย **ถูกที่สุด** และ **แพงกว่าถูกสุด ฿xxx**
  - ป้าย **🏪 ราคาที่ช่างไปดูมา** สำหรับร้านข้างนอก
  - ป้าย **★ จัดซื้อแนะนำ** + เหตุผล
- แตะเลือกเจ้าไหนก็ได้ ไม่จำเป็นต้องตามที่จัดซื้อแนะนำ

### กดอนุมัติ
- **✅ อนุมัติรายการนี้** — ทีละรายการ เลือกเจ้าเองได้
- **✅ อนุมัติทั้งใบ N รายการ** — ใช้ตัวที่จัดซื้อแนะนำ (★) ของทุกรายการ
- **❌ ไม่อนุมัติ** — ต้องพิมพ์เหตุผลก่อน

ก่อนกด ระบบจะบอกผลที่จะเกิดขึ้นในกรอบด้านล่างเสมอ:
- เลือกผู้ขาย → *"จัดซื้อจะเปิด PO กับผู้ขายรายนี้"*
- เลือกราคาที่ช่างไปดูมา → *"ให้ช่างไปซื้อเอง แล้วเบิกคืนตามใบกำกับภาษี"*

ชื่อและเวลาที่กดถูกบันทึกถาวร ดูย้อนหลังได้ที่ปุ่ม **🕘 ประวัติ** หรือชีต `History`
