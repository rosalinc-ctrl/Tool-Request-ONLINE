# ชุดทดสอบ (ไม่บังคับ / optional)

ทดสอบ logic ฝั่งเซิร์ฟเวอร์และตัว render ของหน้าเว็บบนเครื่องได้ **โดยไม่ต้อง deploy**
โดยจำลอง (mock) บริการของ Google Apps Script ด้วย Node.js

```bash
node tests/run.js          # ทดสอบ workflow ทั้งหมดฝั่งเซิร์ฟเวอร์ (81 เคส)
node tests/client-test.js  # ทดสอบการ render ของทั้ง 4 หน้า (49 เคส)
```

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้ง package ใดๆ

- `mock.js` — จำลอง SpreadsheetApp / DriveApp / MailApp / CacheService / LockService ฯลฯ
- `run.js` — ไล่ตั้งแต่ช่างส่งคำขอ (รหัสพนักงาน) → จัดซื้อร่างสเปค → ช่างยืนยันสเปค →
  เทียบราคา 3 เจ้า → จัดซื้อแนะนำ → ผู้บริหารอนุมัติ → เปิด PO / ช่างซื้อเอง →
  ใบเสร็จ → สรุปงานค้าง พร้อมตรวจว่าราคาผู้ขายไม่หลุดไปหน้าช่าง
- `client-test.js` — เอา DTO จริงจากฝั่งเซิร์ฟเวอร์มา render หน้าช่าง/จัดซื้อ/ผู้บริหาร/ฟอร์ม

> ใช้สำหรับตรวจ logic เท่านั้น การทดสอบจริงบนมือถือให้ทำตามขั้นตอนใน `README.md`
